# My Portfolio

Personal portfolio of Nabin Bogati, senior backend engineer. Live at [nabinbogati.com.np](https://nabinbogati.com.np).

## 🛠 Tech Stack

**Frontend:** React, TypeScript, Tailwind CSS, Vite
**Hosting:** GitHub Pages

## Updating content

All text (headline, what I build, what drives me, projects, the "now" section, experience, certifications) lives in `data/profile.ts`.

```bash
npm install
npm run dev      # local preview
npm run deploy   # build and publish to GitHub Pages
```
